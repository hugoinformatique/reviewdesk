=== ReviewDesk ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0

Ajoute le bouton de relecture ReviewDesk à votre site WordPress, sans toucher au code.

== Installation ==

1. Extensions › Ajouter › Téléverser une extension : choisissez reviewdesk-wordpress.zip, installez, activez.
2. Réglages › ReviewDesk : collez la ligne d’installation copiée dans ReviewDesk (Installer › WordPress), enregistrez.
3. Ouvrez votre site : le bouton « Faire un retour » apparaît en bas de la page.

L’adresse du site doit figurer dans les adresses autorisées du projet ReviewDesk.
